Live shared boards — teach and type together (one-time setup)

How it works. Press 👥 Share board to get a code (e.g. QK7MP). Students type the code and press Join — or simply open whiteboard.html?board=QK7MP — and everyone sees and edits the same board live: the text, the pen strokes and any pasted images.

One-time setup (teacher only, ~5 minutes, free). Because this site is fully static, live sync needs a small free database from Google Firebase:

  1. Go to console.firebase.google.com → Add project (Analytics not needed).
  2. Build → Realtime Database → Create database → start in test mode. Then, under Rules, set:
    { "rules": { "boards": { ".read": true, ".write": true } } }
  3. Project settings → Your apps → Web app </> → Register → copy the firebaseConfig values.
  4. Open whiteboard.html, find WB_FIREBASE near the top of the script, and paste your values there. Push the file to the site.

Notes. If two people type in the very same instant, the later keystroke wins — take turns or work on different lines. Anyone with a board's code can edit that board, so treat codes like the key to the classroom, and use a fresh board (new code) per lesson.
